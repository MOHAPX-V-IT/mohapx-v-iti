# MOHAPX-V-IT

Персональный сайт Алексея Марышева — ИИ-инженера.
Один самодостаточный HTML-файл: без сборки, без зависимостей, без бэкенда.
Фото и фон зашиты в файл, поэтому сайт работает даже без интернета.

- Тёмная и светлая темы
- Русская и английская версии
- Полностью адаптивен

## Как обновить

Открыть `index.html` в любом редакторе, поправить текст, залить обратно.
Тексты продублированы: `<span class="ru">` и `<span class="en">` — правь обе.
