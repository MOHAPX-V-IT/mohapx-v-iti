# MOHAPX-V-IT

Персональный сайт Алексея Марышева — AI Forward Deployed Engineer (FDE), AI Engineer / Full-stack, более 3 лет в IT.
Статический сайт без обязательной сборки и бэкенда. Главная страница использует локальные CSS, JavaScript, фотографию и шрифты из `assets/` и `fonts/`.
Вращающаяся объёмная корона реализована на локальной Three.js; при недоступности WebGL остаётся исходный SVG-знак. Сайт не обращается к внешним CDN во время просмотра.

- Тёмная и светлая темы
- Русская и английская версии
- Полностью адаптивен
- Анимацию можно остановить; системная настройка уменьшения движения соблюдается

## Эффекты и GitHub

На главной адаптированы предоставленные компоненты 21st.dev: Halftone Wordmark
Footer (точечный логотип с пружинами и волной по клику), Tilted Grid Hero
(изогнутая лента из 16 граней на карточку), Shiny Button и Background Paths.
Из шести исходных промптов четыре уникальны: второй/третий и четвёртый/пятый
повторяются. Дополнительно через прямой коннектор 21st.dev получен GitHub Activity Grid
(wensity): адаптированы единая движущаяся подсказка и появление дней от новых
к старым, демонстрационные данные заменены реальным GitHub. Это реализации на HTML/CSS/JavaScript в `assets/enhancements.*`,
сохраняющие статический хостинг; установка React, shadcn и Tailwind не требуется.
В React-проекте исходные TSX-компоненты размещались бы в `components/ui`,
но здесь такого каталога и React-сборки нет.

Лента использует локальные авторские SVG-обложки реальных открытых проектов;
это иллюстрации, а не скриншоты интерфейсов. Оранжевая палитра, обе темы,
RU/EN и исходная Three.js-корона сохранены. Кнопка над лентой останавливает
новые эффекты; вращение короны управляется её исходной кнопкой.

Статистика подключена к `MOHAPX-V-IT`, подтверждённому Git remote. Браузер
читает локальный `assets/github-stats.json`. Обновление вручную:

```text
python build/update_github.py
```

Скрипт стандартной библиотеки Python получает профиль и все страницы публичных
репозиториев через официальный REST API GitHub, а календарь — из публичной
страницы contributions GitHub. Сумма звёзд включает собственные репозитории,
исключая форки. Отображается дата снимка. При ошибке GitHub или изменении
разметки предыдущий снимок сохраняется; при недоступности JSON интерфейс
показывает ошибку и ссылку на профиль вместо вымышленных нулей.
Календарь повторяет видимость профиля: GitHub может включать обезличенные
вклады в закрытые репозитории, если владелец включил их отображение.

Новый workflow `.github/workflows/github-stats.yml` обновляет снимок ежедневно
и вручную через workflow_dispatch. Он начнёт работать после публикации этих
файлов в основной ветке при включённых GitHub Actions и разрешённой записи
в репозиторий. Для существующего branch-based GitHub Pages workflow явно
запрашивает пересборку после обновления данных; при пользовательском Pages
workflow потребуется подключить его к обновлению снимка. Ключи GitHub в клиент не добавляются. Приватные исходники и
названия закрытых репозиториев не загружаются.

Проверка парсера и защиты последнего снимка: `python -m unittest discover -s build -p "test_github_stats.py"`.

## Как обновить

Открыть `index.html` в любом редакторе, поправить текст, загрузить сайт вместе с `assets/` и `fonts/`.
Тексты продублированы: `<span class="ru">` и `<span class="en">` — правь обе.

Локальная проверка: `python -m http.server 8765 --bind 127.0.0.1`, затем `http://127.0.0.1:8765/`.

Файлы новостей не менялись при редизайне. Генераторы используют зафиксированную прежнюю тему `build/legacy-theme.css`, поэтому изменения главной не переоформляют новости автоматически.

Дизайн вдохновлён [Comblock](https://www.comblock.ru/); исходная палитра и корона сохранены. Технические источники и лицензия Three.js перечислены в `assets/README.md`.

## Fieldwork: персональный редизайн

Главная использует `assets/portfolio.css` и `assets/portfolio.js` поверх общей
оболочки. Первое чтение: профиль → три избранных кейса → подход → опыт и стек
→ открытые проекты → контакт. Полные старые кейсы, история работы, остальные
результаты и личные тексты сохранены в раскрываемых блоках. Все три избранных
кейса доступны без JavaScript; фильтры появляются только после инициализации.

Статистика GitHub и её обновление сохранены. Переключатель эффектов останавливает
также корону; отдельная кнопка вращения позволяет управлять ею независимо.
Главная соблюдает системную настройку reduced motion. Навигация и фильтры
работают с клавиатуры, календарь поддерживает стрелки и Escape для подсказки.

Дизайн главной не переносится на журнал и калькулятор. Их генератор использует
стабильные `build/calculator-header.html` и `build/calculator-footer.html`.
Это защищает пересборку от структуры новой главной. Источники компонентов
21st.dev и атрибуция перечислены в `assets/README.md`.
