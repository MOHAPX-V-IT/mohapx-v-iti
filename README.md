# MOHAPX-V-IT

Персональный сайт Алексея Марышева — AI Forward Deployed Engineer (FDE), AI Engineer / Full-stack, более 3 лет в IT.
Статический сайт без обязательной сборки и бэкенда. Главная страница использует локальные CSS, JavaScript, фотографию и шрифты из `assets/` и `fonts/`.
Вращающаяся объёмная корона реализована на локальной Three.js; при недоступности WebGL остаётся исходный SVG-знак. Сайт не обращается к внешним CDN во время просмотра.

- Тёмная и светлая темы
- Русская и английская версии
- Полностью адаптивен
- Анимацию можно остановить; системная настройка уменьшения движения соблюдается

## Как обновить

Открыть `index.html` в любом редакторе, поправить текст, загрузить сайт вместе с `assets/` и `fonts/`.
Тексты продублированы: `<span class="ru">` и `<span class="en">` — правь обе.

Локальная проверка: `python -m http.server 8765 --bind 127.0.0.1`, затем `http://127.0.0.1:8765/`.

Файлы новостей не менялись при редизайне. Генераторы используют зафиксированную прежнюю тему `build/legacy-theme.css`, поэтому изменения главной не переоформляют новости автоматически.

Дизайн вдохновлён [Comblock](https://www.comblock.ru/); исходная палитра и корона сохранены. Технические источники и лицензия Three.js перечислены в `assets/README.md`.
